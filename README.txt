AVATAR FORGE — FRIEND TESTER BUILD

1. Double-click "Avatar Forge.exe".
2. Choose an avatar image (transparent PNG works best).
3. Click Start camera tracking and allow webcam access.
4. Adjust the tracking sliders.
5. Click Download OBS overlay.

OBS / STREAMLABS
- Add a Browser Source.
- Enable Local file and select the downloaded *-obs-overlay.html file.
- Set Width to 1920 and Height to 1080.
- Keep the source background transparent and allow camera access.

The desktop app keeps avatar artwork and settings on the local computer.
The exported OBS overlay needs an internet connection to load its face-tracking engine.

This is an unsigned tester build. Windows may show a SmartScreen warning because it has not been code-signed.
